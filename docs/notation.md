# 符号约定与数学阅读提示

[返回首页](../README.md) · [公式速查](formula-sheet.md)

各章在第一次使用重要符号时给出定义；本页用于跨章查询。除非另有说明，对数均为自然对数，信息量单位为 nat。

## 1. 数据、模型与目标

| 符号 | 约定 |
| --- | --- |
| $X,x$ | 随机变量与其取值；$x$ 也可表示一个完整数据向量 |
| $x=(x_1,\ldots,x_n)$ | 一个样本的 $n$ 个分量；$n$ 是数据维数或序列长度 |
| $x^{(k)}$ | 数据集中第 $k$ 个样本，区别于单个样本的第 $k$ 维 $x_k$ |
| $N,\mathcal{D}$ | 样本数量与数据集 $\{x^{(k)}\}_{k=1}^{N}$ |
| $p_{\mathrm{data}}$ | 未知的真实数据分布 |
| $p_\theta$ | 由模型参数 $\theta$ 决定的分布 |
| $c,y$ | 生成条件与分类标签；具体含义由所在章节定义 |
| $z,d_z$ | 潜变量及其维数 |
| $q_\phi(z\mid x)$ | VAE 中参数为 $\phi$ 的近似后验 |
| $\ell_N(\theta)$ | 数据集的对数似然，通常取求和形式 |
| $\mathcal{L},\mathcal{J}$ | 学习目标；每章明确是最大化还是最小化 |

GAN 的 $\phi$ 表示判别器或 critic 参数，与 VAE 的推断参数是不同对象。不同章节复用字母时，以局部定义为准。

## 2. 概率与信息量

| 写法 | 含义 |
| --- | --- |
| $x\sim p$ | 按分布 $p$ 采样 |
| $p(x,y),p(x\mid y),p(x)$ | 联合分布、条件分布、边缘分布 |
| $X\perp Y\mid Z$ | 给定 $Z$ 后，$X,Y$ 条件独立 |
| $\mathbb{E}_{p}[f(X)]$ | 在分布 $p$ 下对 $f$ 取期望 |
| $D_{\mathrm{KL}}(p\Vert q)$ | 从 $p$ 到 $q$ 的 KL；期望在 $p$ 下计算 |
| $H(p),H(p,q)$ | 熵与交叉熵；离散时 $D_{\mathrm{KL}}(p\Vert q)=H(p,q)-H(p)$ |
| $\operatorname{JS}(p,q)$ | JS 散度，使用混合分布 $(p+q)/2$ 定义 |
| $W_1(p,q)$ | 一阶 Wasserstein 距离，需指定底层距离 |

离散情形的 $p(x)$ 是概率质量，连续情形的 $p(x)$ 是密度。连续密度可以大于 $1$，连续 NLL 也可以为负，不能直接套用离散概率的取值范围。

KL 方向不能交换。有限 KL 需要相应的绝对连续性与可积性；涉及“去掉与参数无关项”的分解时，也需要这些项有定义，不能对无穷大直接相减。

## 3. 高斯与线性代数

统一使用 $\mathcal{N}(\mu,\sigma^2)$ 表示一维高斯、$\mathcal{N}(\mu,\Sigma)$ 表示多维高斯，**第二个参数是方差或协方差**。

| 符号 | 含义 |
| --- | --- |
| $I$ | 与当前维数匹配的单位阵 |
| $\operatorname{diag}(v)$ | 以 $v$ 为对角元素的对角矩阵 |
| $a\odot b$ | 逐元素相乘 |
| $\|x\|_2$ | 欧氏范数；$\|x\|_2^2$ 是平方误差之和 |
| $\nabla_\theta$ | 关于参数 $\theta$ 的梯度 |
| $J_f$ | 变换 $f$ 的 Jacobian 矩阵 |
| $\det J,\operatorname{tr}J$ | 行列式与迹 |
| $\operatorname{sg}[x]$ | 前向保持 $x$，反向停止其梯度 |

如果网络输出 $s=\log\sigma^2$，标准差为 $e^{s/2}$；Flow 中若输出 $a=\log\sigma$，标准差为 $e^a$。**对数方差与对数标准差相差一倍**，不能混用。

## 4. 各模型的专用约定

| 模型 | 本笔记的约定 |
| --- | --- |
| 自回归 | $x_{<i}=(x_1,\ldots,x_{i-1})$；第一项没有历史输入 |
| VAE | $p(z)$ 是生成先验，$p_\theta(z\mid x)$ 是真实后验，$q_\phi(z\mid x)$ 是近似后验 |
| Flow | $x=f_\theta(z)$ 是生成方向，$z=f_\theta^{-1}(x)$ 是求逆方向 |
| GAN | $G_\theta$ 是生成器，$D_\phi$ 是真假概率判别器，$f_\phi$ 是实值 critic |
| 扩散 | $x_0$ 是干净数据，$x_T$ 是末端噪声；$q$ 是固定前向过程，$p_\theta$ 是反向模型 |

扩散中的 $\beta_t$ 是一步噪声方差，$\alpha_t=1-\beta_t$，$\bar\alpha_t=\prod_{s=1}^{t}\alpha_s$；$\tilde\beta_t$ 则是条件于 $x_0$ 的前向后验方差。它们都不是 β-VAE 的目标权重。

## 5. 读公式时先问四个问题

1. **变量是什么？** 哪些是观测、潜变量、条件、待优化参数？
2. **期望对谁取？** 从数据、先验、近似后验还是模型分布采样？
3. **等号还是近似？** 是恒等式、模型假设、下界，还是有限样本估计？
4. **优化方向是什么？** 最大化对数似然 / ELBO，或最小化 NLL / 负 ELBO，符号要一致。

一个模型还应区分三种误差：模型族本身的表示限制、有限样本带来的统计误差，以及未求得最优参数的优化误差。“公式可精确计算”只说明计算对象明确，不保证模型等于真实分布。
